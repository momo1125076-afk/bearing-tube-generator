# 回归检查（每次改几何 / 页面后跑一遍）

## 自动检查
```bash
cd bearing_tool_web
npm i puppeteer-core            # 只需一次；需本机装有 Chrome（CHROME=路径 可指定）
pip install trimesh numpy cadquery manifold3d
python3 -m http.server 8765 &   # 在网页目录起静态服务
node tests/regression_browser.mjs http://127.0.0.1:8765/index.html tests/out   # 页面端到端 + 点击导出
python3 tests/regression_geom.py tests/out                                    # 对导出文件做几何检查
```
两步都输出「全部通过」即可；任何一项 FAIL 退出码为 1。

| 检查 | 在哪一步 | 通过标准 |
|---|---|---|
| 叠加层支撑脚（A 模式） | 浏览器 + 几何 | 第 2..N 层脚体积 > 5 mm³，底面悬空 < 0.5 mm²；关掉支撑脚时自检必须报警 |
| 层间嵌合（V 形止口） | 浏览器 + 几何 | 默认开启并在结果区显示；下层单元顶面有凸环（单元高 > 层距）；嵌合深度、止口间隙写进分享码 |
| 整体打印（组装态） | 浏览器 + 几何 | 「整体打印 STL」能导出；水密、1 个实体；底座以上陡悬垂 < 20 mm²；与轴承相交 = 0；整体打印模式下取消长螺丝，A 给出暂停放轴承的高度 |
| B 模式叠加层贴合 | 浏览器 | 悬空 0 mm² |
| 悬垂斜面 | 几何 | 每种单元除底面外，与水平夹角 < 45° 的朝下面积 < 8 mm² |
| 底座 O 圈槽 | 几何 | 两道槽处内孔 Ø = 槽底 Ø（±0.3），比旁边的内孔大 |
| M3 孔 | 几何 | 每种单元亏格 ≥ 1（有穿孔） |
| 长螺丝孔（B） | 几何 | 亏格 > 1 |
| 干涉 | 浏览器 + 几何 | 页面自检「无干涉」；轴承∩打印件 = 0；打印件之间相交 = 0 |
| 水密 | 几何 | 每种单元水密；整管（全部打印件并集）水密且为 1 个实体 |
| 导出 | 浏览器 | 单元种类 STL、底座 STL、装配 STEP 都能下载 |
| 分享码 / 选项卡 / 反推 | 浏览器 | 分享码导入后参数还原；反推给出方案；反推约束是同款折叠面板 |
| 页面布局 | 浏览器 | 生成按钮在预览正下方；全部展开/收起有效且写入 localStorage；窄屏单栏；无 JS 报错 |
| 打赏码 / 「模型仅供参考」 | 浏览器 | 图片已加载、文字可见 |

## 手动目测清单
- [ ] A 模式 2/3/4 层：结果区「叠加层支撑脚自检」每层都是「脚✔」
- [ ] 3D 预览里上层单元贴面下方有 V 形 45° 斜面落在下层顶面（不悬空）
- [ ] 打开切片软件看底座：两道 O 圈槽、M3 孔、长螺丝孔都在
- [ ] 改倾斜角 10° / 35°、每层数量 4，自检无「支撑脚缺失」
- [ ] 整体打印：切片软件里在结果区给出的高度（A）加暂停，确认轴承能竖直放进腔；B 打完后轴承从外侧槽推入

## STEP 导出按钮回归（v20）
```
node tests/regression_step_export.mjs http://127.0.0.1:8781/index.html /tmp/sx_A A
node tests/regression_step_export.mjs file:///绝对路径/bearing_tool_web/index.html /tmp/sx_B B
python3 tests/check_step_files.py /tmp/sx_A    # CadQuery 读入：每个 STEP 至少 1 个有效实体
```
真实点击 单元 / 底座 / 整管 / 装配 / 轴承 / 整体打印 六个 STEP 按钮，检查下载文件非空、页面提示「✅ 已下载」、无未捕获异常；生成前点击也必须有提示，不能静默。

## v21 新增检查
- 默认：层数 3、圆形底座（baseAF=0）、slopeDrop=3、生成方式为融合，拆分参数与分件按钮隐藏。
- 融合：A/B 导出融合整体 STL + STEP；STEP 用 CadQuery 校验 isValid 且实体数 = 1（check_step_files.py）。
- 拆分：切到拆分 + 打印间隙 0.1 后无干涉、层间嵌合开；分享码含 printWhole / splitGap；0.02 会被夹到 0.05；旧分享码缺省为融合。
- 几何：A 叠加层单元高度 ≥ 层距 + slopeDrop（斜面下移存在）；底座 X/Z 外径相等 = Ø27。A 开启斜面下移时，分件单独打印的悬垂门槛放宽到 40 mm²（融合件仍要求 < 25 mm²）。

## v6 更新
- **打印悬垂处理（斜面）**：参数「打印悬垂处理（斜面）」(1/0，默认 1) 与「最大悬垂角」(默认 45°，与水平面夹角)。
  打印方向：单元管轴竖直、底面贴打印台。轴承轴线相对水平倾斜 α，原先轴承腔、M3 孔、螺帽沉孔这些**倾斜圆孔的顶部**几乎水平（只倾斜约 α），
  上一层单元在轴承处的下沿就是这样形成悬垂的。处理方式：
  - 倾斜孔/腔顶改为「泪滴」尖顶：切点角 φ0 = asin(cos(最大悬垂角)/cos α)（α=25° 时约 51.3°），尖顶两侧斜面与水平面夹角正好等于设定值；
  - B 模式侧面装入槽的平顶改为绕槽向倾斜 (最大悬垂角 − α) 的斜面，最低处仍等于腔半径，轴承照样能装入。
  - 只多切掉空气，不碰轴承、凸台和腔间隙；紧邻层距按不带尖顶的实体计算，**层距和总长不变**（尖顶冒出端面时只在对接面留一个小开口）。
  - 悬垂面积（α=25°，每层 3 个）：A 12.06 → 1.13 mm²，B 70.62 → 2.25 mm²。剩下的约 1 mm² 是 0.4 mm 高的内圈凸台下沿，可以忽略。
  - 分析脚本：`overhang.py`（trimesh），着色图：`ohplot.py`。
- 页面加了项目说明（可折叠）、每个参数下面的小字注释，按钮改为网格等宽对齐，窄屏会切成单栏。
- 分享码仍为 BT1，旧码里没有新字段的按默认值（开启、45°）处理。

## 参数分享 / 快速导入（可复现教程）
- 页面左侧「分享 / 导入参数」：
  - **复制分享码**：得到短码 `BT1.…`（base64url，内含版本号 + 单元模式 + 相对该模式默认值的差异字段）。
  - **复制分享链接**：当前页 URL + `#p=BT1.…`，发给别人打开即可还原全部参数。
  - **写入地址栏**：把当前参数写进 hash，方便继续分享。
  - **导入参数**：粘贴分享码或整段链接，一键还原；可勾选「导入后自动生成模型」。
- 打开带 `#p=…`（或 `?p=…`）的链接后，工具会自动还原参数并生成模型，相当于参数驱动的可复现教程。
- 改任意参数后，地址栏 hash 会自动更新（便于再分享）。导入失败会提示「版本不匹配」或「格式错误」。

## 单元的定义与拼接（对齐原 STEP 中的 120° 扇形块）
- **单元** = 一个扇形块，含 1 个 MF63ZZ：外圆 Ø27（tubeOD），中心通道 Ø13.5（软弹 Ø13 + 2×0.25），扇形角 360/N，
  高度 = 层距 H。单元里有：本轴承的避让腔 + 外侧装入槽、M3 销轴孔（通孔 + 螺帽沉孔 + 螺母槽/自攻孔）、内圈支撑凸台、1 个长螺丝孔。
  相邻轴承伸过拼接面的部分（轴承/螺帽/螺母本体）也会在本单元里让开，保证拼接面两侧孔位一致。
- **先算单元**：腔、孔、壁厚、干涉检查都在单个单元上做（同层相邻单元、长螺丝、通道壁、拼接面）。
- **再拼接**：把单元绕管轴旋转 k·360/N（+ 层间错角）、沿管轴平移 L·H 复制成整管。打印件种类：底层（长螺丝螺帽沉孔）、中间层、顶层（长螺丝自攻盲孔）；不用长螺丝时只有 1 种。
- **层距「紧邻」模式**（默认）：H = 单层切削体（轴承 + 腔 + 螺丝/螺帽/螺母实占空间）的轴向高度 + 2×endPad，即每个单元刚好装下自己的硬件、不伸进相邻单元。可切换「手动」，小于最小值会报警。
  装入通道（螺帽/螺母从外面装入的路径）允许开到单元上下面或拼接面，装配前装好，叠层后被相邻单元封住。
- 层间错角：可选不错开 / 错开半角 / 自定义。勾选「计算错角对比」会算出各层腔孔互相嵌套时的参考层距（默认参数：不错开 9.5 mm，错开 60° 11.5 mm），但嵌套后单元不再独立，所以默认不用。错角 ≠ 0 时长螺丝孔上下对不齐，会报警。

## 底座（v3 新增，堆叠最末端）
- 对应原 STEP 的 solid 15（Ø27×13.7 件）下部 2.4 mm 厚的整圈底板：中心孔 Ø15，3 个 Ø1.9 长螺丝自攻孔 @R10.26，与上面的扇形单元同轴同角度。
- 参数：带底座 baseOn（1/0）、底座厚 baseT（默认 2.4）、中心孔 baseBoreD（默认 Ø15，须 ≥ 软弹通道 Ø13.5）、长螺丝在底座的方式 baseTie：
  - `tap`（默认，原模型做法）：M2 长螺丝从顶层单元的螺帽沉孔穿入，经各层 Ø2.2 通孔，拧进底座 Ø1.8 自攻孔（旋合 = 底座厚）。顶层沉孔深度自动加深，使标准长度螺丝尖端刚好不超出底座底面；
  - `head`：螺帽沉孔开在底座底面（底座厚需 ≥ 螺帽高 + 最小壁厚），顶层自攻盲孔/螺母。
- 位置：底座占 Y∈[−baseT, 0]，顶面与第 1 层单元底面贴合；整管 = 底座 + N 层单元，总长 = baseT + 层数 × 层距（默认 2.4 + 2×11.6 = 25.6 mm）。
- 长螺丝建议（默认 tap 方式）：2 层 M2×22，3 层 M2×35，4 层 M2×45。
- 干涉检查新增：第 1 层轴承/螺丝/螺帽/螺母实体与底座交集、到底座顶面余量、中心孔是否挡软弹、中心孔与长螺丝孔壁厚、自攻旋合长度/沉孔是否放得下。

## M3 销轴（每个轴承 1 根，孔轴线 = 轴承轴线，含倾斜 α）
- 螺丝弦向穿过单元壁 → 支撑壁 → 轴承内孔（Ø3）→ 支撑壁；两侧各有 Ø4.2×0.4 凸台只顶内圈，外圈与腔壁留 0.3 间隙自由转动。
- 默认：通孔 Ø3.3，圆柱头沉孔 Ø5.8×3.2（可选半圆头 Ø6.0×1.9），螺帽侧壁 2.2，螺母侧壁 1.2，M3 六角螺母槽 对边 5.6 × 厚 2.6（开到外表面以便放入）；
  或 Ø2.5 自攻孔；或 Ø3 钢销（孔 Ø2.95，最紧凑，每层可到 5 个）。
- 页面给出建议长度：默认 **M3×12** 圆柱头（夹持 7.3 mm + 螺母 2.4 + 伸出 ≥0.5）。

## 长螺丝补强
- 每个单元 1 根，轴向贯穿所有层，默认 **M2**（与原模型 Ø2.0 通孔 / Ø1.9 自攻孔一致），半径 10.26（原模型相同），
  角度偏移自动搜索（默认参数得到 54.5°，原模型 48.3°：48.3° 时会碰到 M3 螺帽沉孔，因此偏开 6°）。
- 有底座（默认）：顶层螺帽沉孔 → 拧进底座自攻孔（见上）。不带底座：底层螺帽沉孔，顶层 Ø1.8 自攻盲孔（或螺母槽），2 层 M2×18，3 层 M2×30，4 层 M2×40。

## 估算模型（按单元累加，⚠ 需实测校准）
每个单元一个接触点；第 L 层位于 L·H，软弹头部到达后开始接触，接触行程 = 软弹长 + 法兰接触弦长；层距 < 软弹长时多层同时接触。
系数 kn、μ、crr、kI、轴承旋转质量都是估计值。

## 导出
单个单元 STEP/STL、底座 STEP/STL、全部打印件种类 STL（含底座）、整管 STL/STEP（底座 + 单元）、装配 STEP（底座 + 单元 + 轴承）、轴承 STEP。整管 STL 是多个贴合实体的合集，打印请用「打印件种类 STL」或单件。
命令行：`python3 bearing_tube.py --perLayer 3 --layers 4 --out out_py`（调用 geom.js，与网页同一套几何）；`compare.py` 对比原 STEP 轴承位置；`verify.py` 检查导出件。

## 已知限制
- 用 M3 螺丝 + 螺母/螺帽时每层最多 4 个（轴承轴线半径 9.44 由软弹直径和吃深决定，螺丝弦长约 13 mm），5 个要用钢销，6 个即使用钢销也会干涉。N=4 时扇形里找不到放长螺丝的位置（请设 0 或改钢销）。
- 原模型的 Ø34 外壳（solid 12）、Ø27 延长管（solid 13/14）和表面文字没有做；底座只取 solid 15 的底板，扇形柱部分由参数化单元代替。

## 层间嵌合 / 整体打印（组装态）（v18）
- **分件打印 + 层间嵌合**（默认）：下层单元顶面凸起一圈 45° V 形止口环（高 = `mateDepth`，默认 1.0 mm，位于管壁中间），上层单元底面开对应的 V 形槽，法向间隙 `mateGap`（默认 0.2 mm）。叠起来互相卡住、不会错位；两面都是 45° 斜面，竖直打印不悬垂，单元底面仍是平的。凸环只取上层原本是实体的部分，不碰轴承腔、M3 孔、长螺丝孔、O 圈槽。**层距不变**。`mateDepth = 0` 关闭。
- **整体打印（组装态）**：`printWhole = 1`，或者不改参数，直接点「整体打印 STL / STEP」。底座和全部单元合并成 1 个实体（层间重叠部分直接合并、不留间隙）。不再需要长螺丝，所以顶部不露螺丝头和孔。同时沿每根 M3 轴线开一条 Ø(螺帽+0.4) 的泪滴形通道通到管外，打印完能从外面拧螺丝。管和底座交界处的水平台阶（底座六角平面、底座出口孔）改成 45° 倒角，整体竖直打印不悬垂。
  - A 模式：打印中途要**暂停**放轴承。在结果区给出的高度（离打印台）暂停，把该层轴承竖直放进腔里，再继续打印。打完后从敞开侧拧 M3。
  - B 模式：不用暂停。打完后轴承从外侧装入槽沿径向推入，再拧 M3。
- 分享码里新增 `printWhole / mateDepth / mateGap` 三项。旧分享码导入时这几项用默认值。

## v21 更新：融合 / 拆分切换、斜面下移、圆形底座、新布局

- **生成方式（默认「融合为单一实体」）**：导出区顶部单选「融合为单一实体 / 拆分为多件」，对应参数 `printWhole`（1 融合 / 0 拆分），写入分享码；旧分享码没有这个键时按默认值融合导入。
  - 融合：底座 + 全部层布尔并集为 **1 个有效实体**，主按钮「⬇ 融合整体 STEP」，另有融合整体 STL；不需要长螺丝。A 模式按结果区给出的高度暂停放轴承，B 模式打完从外侧槽推入轴承。
  - 拆分：显示分件导出（单元 / 底座 / 分件拼接 / 装配 / 轴承）和拆分专用参数（嵌合深度、打印间隙）。
- **打印间隙 `splitGap`（仅拆分）**：默认 0（无间隙），可调 0.05–0.3 mm（步进 0.05，0 < 输入 < 0.05 自动夹到 0.05，> 0.3 夹到 0.3）。它**取代**旧的止口间隙 `mateGap`：程序内部 `mateGap = splitGap`，同时作用于 V 形止口与「斜面下移裙边」和下层单元的侧面/顶面。旧分享码里的 `mateGap` 不再生效。
- **衔接斜面下移 `slopeDrop`（A 模式叠加层，默认 3 mm，0 = 关闭，上限 0.6×层距）**：上层支撑脚的 45° 斜面整体向下平移，楔块向下伸进下层敞开侧上方的空区，包住螺丝孔周围并托住上层轴承下方；伸下去的部分会减去下层全部单元和全部轴承切削体，所以零干涉，底面仍为 45° 斜面。拆分单独打印时裙边底面朝下（贴在下层上），需要支撑；推荐融合打印。
- **默认层数 3**。
- **圆形底座**：`baseAF` 默认 0（Ø27 圆柱，与参考 STEP 一致），填 >0 仍可恢复六角平面。
- **布局**：3D 预览占主区左上，导出区在右侧整列，生成按钮在预览下方，设置值 / 结果在底部。

## v30 / v31：贯通螺丝补强孔、外形对齐参考 STEP、层间距离与外径

- **贯通螺丝孔**（「螺丝与孔 · 长螺丝补强」分区）：孔型默认「贯通通孔」——从底座底面直通到顶层顶面，融合 / 拆分都生效。
  - `reinfHoleD` 孔径：默认 **2.5**，**0 = 不生成该孔**，其余夹紧到 1.5–4（M2 过孔 2.2–2.5，自攻 1.8，参考 STEP 为 2.0）。
  - `tieNum` 数量（≤ 每层单元数，均布），`tieR` 半径（按 Ø27 给定，默认 10.26；外径变化时自动 +(外径−27)/4（保持在管壁中部）），`tieOffsetDeg` 角度（自动找角度可关）。
  - 孔与底座 O 圈槽槽底相交（参考 STEP 同样如此），只在槽底开一个小窗口，不影响 O 圈压在管子上的密封面。
  - 旧版「底座沉孔 + 顶层自攻盲孔」仍可在「孔型」里选。
- **外形**：`tubeAF` 外圆六角平面对边（默认 25.12，按 Ø27 给定，随外径等比），底座与各层单元同时削平，对齐参考 STEP；0 = 纯圆。
- **层间距离**：「层距模式」紧邻（自动最小，默认）/ 手动；手动值小于不干涉下限时默认按下限生成并提示，也可选「保留并报警」。
- **单元外径** `tubeOD`：默认 27，建议 25–32；底座外径、六角平面、嵌合环、贯通孔半径随之联动，生成后自动做干涉检查。
- 分享码包含以上所有参数；旧分享码缺少的新参数取默认值（t30 分享码里的 `tieHoleD` 会映射为 `reinfHoleD`）。

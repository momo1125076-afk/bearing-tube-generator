# 软弹轴承管 参数化生成器（v3：底座 + 扇形单元 + 紧邻叠层 + M3 销轴 + 长螺丝补强）

## 快速开始

网页版本的运行依赖已包含在 `lib/` 中，不需要安装 npm 包或联网。需要 Python 3 和支持 WebAssembly 的现代浏览器。

## 打开方式
双击 `start.bat`（Windows）或运行 `./start.sh`（需 Python 3），浏览器打开 http://localhost:8765/index.html 。
不能直接双击 index.html（file:// 下 WASM 加载会失败）。依赖都在 `lib/`，不需要联网。

## 项目文件

- `index.html`、`main.js`、`geom.js`、`physics.js`：网页界面、几何生成与估算模型。
- `lib/`：网页离线运行所需的打包脚本与 WebAssembly 文件。
- `examples/`：默认参数的 STEP、STL 示例。
- `bearing_tube.py`、`test_node.mjs`、`scan.mjs`：命令行生成及开发辅助脚本。
- `verify.py`、`compare.py`：模型验证与原模型对比脚本。

## 命令行与开发

网页版本不需要以下步骤。命令行生成需要 Node.js、npm 和 Python 3，在项目目录执行：

```bash
npm install
python3 bearing_tube.py --perLayer 3 --layers 4 --out out_py
```

生成文件默认放在 `out_py/`，中间文件放在 `out/`。直接运行 `test_node.mjs` 导出时须先创建 `out/`。`verify.py` 另需 CadQuery 和 trimesh；`compare.py` 另需 CadQuery、NumPy 和未随项目提供的原始 `orig.step`，请按脚本中的路径准备。

## 单元的定义与拼接（对齐原 STEP 中的 120° 扇形块）
- **单元** = 一个扇形块，含 1 个 MF63ZZ：外圆 Ø27（tubeOD），中心通道 Ø13.5（软弹 Ø13 + 2×0.25），扇形角 360/N，
  高度 = 层距 H。单元里有：本轴承的避让腔 + 外侧装入槽、M3 销轴孔（通孔 + 螺帽沉孔 + 螺母槽/自攻孔）、内圈支撑凸台、1 个长螺丝孔。
  相邻轴承伸过拼接面的部分（轴承/螺帽/螺母本体）也会在本单元里让开，保证拼接面两侧孔位一致。
- **先算单元**：腔、孔、壁厚、干涉检查都在单个单元上做（同层相邻单元、长螺丝、通道壁、拼接面）。
- **再拼接**：把单元绕管轴旋转 k·360/N（+ 层间错角）、沿管轴平移 L·H 复制成整管。打印件种类：底层（长螺丝螺帽沉孔）、中间层、顶层（长螺丝自攻盲孔）；不用长螺丝时只有 1 种。
- **层距「紧邻」模式**（默认）：H = 单层切削体（轴承 + 腔 + 螺丝/螺帽/螺母实占空间）的轴向高度 + 2×endPad，即每个单元刚好装下自己的硬件、不伸进相邻单元。可切换「手动」，小于最小值会报警。
  装入通道（螺帽/螺母从外面装入的路径）允许开到单元上下面或拼接面，装配前装好，叠层后被相邻单元封住。
- 层间错角：可选不错开 / 错开半角 / 自定义。勾选「计算错角对比」会算出各层腔孔互相嵌套时的参考层距（默认参数：不错开 9.5 mm，错开 60° 11.5 mm），但嵌套后单元不再独立，所以默认不用。错角 ≠ 0 时长螺丝孔上下对不齐，会报警。

## 底座（v3 新增，堆叠最末端）
- 对应原 STEP 的 solid 15（Ø27×13.7 件）下部 2.4 mm 厚的整圈底板：中心孔 Ø15，3 个 Ø1.9 长螺丝自攻孔 @R10.26，与上面的扇形单元同轴同角度。
- 参数：带底座 baseOn（1/0）、底座厚 baseT（默认 2.4）、中心孔 baseBoreD（默认 Ø15，须 ≥ 软弹通道 Ø13.5）、长螺丝在底座的方式 baseTie：
  - `tap`（默认，原模型做法）：M2 长螺丝从顶层单元的螺帽沉孔穿入，经各层 Ø2.2 通孔，拧进底座 Ø1.8 自攻孔（旋合 = 底座厚）。顶层沉孔深度自动加深，使标准长度螺丝尖端刚好不超出底座底面；
  - `head`：螺帽沉孔开在底座底面（底座厚需 ≥ 螺帽高 + 最小壁厚），顶层自攻盲孔/螺母。
- 位置：底座占 Y∈[−baseT, 0]，顶面与第 1 层单元底面贴合；整管 = 底座 + N 层单元，总长 = baseT + 层数 × 层距（默认 2.4 + 2×11.6 = 25.6 mm）。
- 长螺丝建议（默认 tap 方式）：2 层 M2×22，3 层 M2×35，4 层 M2×45。
- 干涉检查新增：第 1 层轴承/螺丝/螺帽/螺母实体与底座交集、到底座顶面余量、中心孔是否挡软弹、中心孔与长螺丝孔壁厚、自攻旋合长度/沉孔是否放得下。

## M3 销轴（每个轴承 1 根，孔轴线 = 轴承轴线，含倾斜 α）
- 螺丝弦向穿过单元壁 → 支撑壁 → 轴承内孔（Ø3）→ 支撑壁；两侧各有 Ø4.2×0.4 凸台只顶内圈，外圈与腔壁留 0.3 间隙自由转动。
- 默认：通孔 Ø3.3，圆柱头沉孔 Ø5.8×3.2（可选半圆头 Ø6.0×1.9），螺帽侧壁 2.2，螺母侧壁 1.2，M3 六角螺母槽 对边 5.6 × 厚 2.6（开到外表面以便放入）；
  或 Ø2.5 自攻孔；或 Ø3 钢销（孔 Ø2.95，最紧凑，每层可到 5 个）。
- 页面给出建议长度：默认 **M3×12** 圆柱头（夹持 7.3 mm + 螺母 2.4 + 伸出 ≥0.5）。

## 长螺丝补强
- 每个单元 1 根，轴向贯穿所有层，默认 **M2**（与原模型 Ø2.0 通孔 / Ø1.9 自攻孔一致），半径 10.26（原模型相同），
  角度偏移自动搜索（默认参数得到 54.5°，原模型 48.3°：48.3° 时会碰到 M3 螺帽沉孔，因此偏开 6°）。
- 有底座（默认）：顶层螺帽沉孔 → 拧进底座自攻孔（见上）。不带底座：底层螺帽沉孔，顶层 Ø1.8 自攻盲孔（或螺母槽），2 层 M2×18，3 层 M2×30，4 层 M2×40。

## 估算模型（按单元累加，⚠ 需实测校准）
每个单元一个接触点；第 L 层位于 L·H，软弹头部到达后开始接触，接触行程 = 软弹长 + 法兰接触弦长；层距 < 软弹长时多层同时接触。
系数 kn、μ、crr、kI、轴承旋转质量都是估计值。

## 导出
单个单元 STEP/STL、底座 STEP/STL、全部打印件种类 STL（含底座）、整管 STL/STEP（底座 + 单元）、装配 STEP（底座 + 单元 + 轴承）、轴承 STEP。整管 STL 是多个贴合实体的合集，打印请用「打印件种类 STL」或单件。
命令行：`python3 bearing_tube.py --perLayer 3 --layers 4 --out out_py`（调用 geom.js，与网页同一套几何）；`compare.py` 对比原 STEP 轴承位置；`verify.py` 检查导出件。

## 已知限制
- 用 M3 螺丝 + 螺母/螺帽时每层最多 4 个（轴承轴线半径 9.44 由软弹直径和吃深决定，螺丝弦长约 13 mm），5 个要用钢销，6 个即使用钢销也会干涉。N=4 时扇形里找不到放长螺丝的位置（请设 0 或改钢销）。
- 原模型的 Ø34 外壳（solid 12）、Ø27 延长管（solid 13/14）和表面文字没有做；底座只取 solid 15 的底板，扇形柱部分由参数化单元代替。
